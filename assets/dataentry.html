How I worked

The same steps I would follow on a real client file.

  1. Kept an untouched copy of the raw data and highlighted every problem cell.
  2. Logged each issue with the original value, the correction and the reason.
  3. Re-entered the data in one layout, with dropdowns for region and status and rules for quantity, price and date.
  4. Added formulas for line totals and an email format check, then summarised results with COUNTIF and SUMIFS.
